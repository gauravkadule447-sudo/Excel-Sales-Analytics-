# 📌 Project Overview

This project demonstrates how Microsoft Excel can be used as a powerful Business Intelligence tool to analyze sales performance, profitability, customer performance, and market trends.

Using Power Query, Power Pivot, DAX, Pivot Tables, and advanced Excel features, I developed multiple interactive reports that provide meaningful business insights for decision-making.

The dashboards are built using the **AtliQ Hardwares Sales Dataset**, covering sales, customer performance, market analysis, and profit & loss reports.
